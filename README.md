# lifthex

Lift timestamps and hex durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/lifthex/

## Install / run

```bash
git clone https://github.com/theworker02/lifthex.git
cd lifthex
node src/cli.js
node --test
```
